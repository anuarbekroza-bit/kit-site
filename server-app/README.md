# «Кит» — сайт и админка на своём сервере

- Сайт: https://kit.r-agent.kz
- Админка: https://admin.r-agent.kz (вход по логину и паролю)
- Технологии: Node.js 22 (без внешних пакетов) + база SQLite (`/var/lib/kit/kit.db`), фото в `/var/lib/kit/images`.
- Уровни доступа: Владелец (всё + сотрудники), Администратор (весь контент), Менеджер (товары, каталог, фото).
- Журнал действий, резервная копия базы при каждом сохранении и каждую ночь (`/var/lib/kit/backups`, 30 последних).

Установка / обновление кода на сервере:

    ssh myserver "curl -fsSL https://raw.githubusercontent.com/anuarbekroza-bit/kit-site/main/server-app/install.sh | sudo bash"

Данные (товары, тексты, фото) живут только на сервере и при обновлении кода не трогаются.
Паролей и ключей в этом репозитории нет.

## Голосовое управление ботом (русский и казахский)

Сотрудник отправляет боту «Кит» голосовое (или пишет своими словами) — бот понимает русский, казахский и смесь:
«Поставь цену на брюки карго 13 500», «Бомберді сайттан жасыр», «Добавь товар: шапка зимняя, 5 900, на 3–7 лет», «Заявку 12 в работу».
Перед любым изменением бот показывает, что понял, и ждёт «✅ Да» / «иә».

Включить: админка → «🤖 Telegram-бот» → «🎤 Голосовое управление» → вставить ключ OpenAI (sk-…, platform.openai.com/api-keys; баланс API пополняется отдельно от ChatGPT Plus). Запасной вариант — ключ Google Gemini (AIza…).
Бот сервера тоже понимает голос и текст своими словами: «Как сервер?», «Бэкап жаса», «Когда был последний бэкап?», «Выключи утренний отчёт».

Один ключ на оба бота. Где он берётся (по порядку): ключ из админки → `OPENAI_API_KEY` в `/etc/kit/kit.env` на сервере
(файл не трогается при обновлении; `install.sh` сам переносит туда ключ, если его вписали в службу kit-app или в `.env`).
После правки `/etc/kit/kit.env` вручную: `sudo systemctl restart kit-app`.

Код: `voice.js` (распознавание и разбор команды), обработка — в `bot.js` и `server-bot.js`.
