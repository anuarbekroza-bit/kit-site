# «Кит» — детская и подростковая одежда, Астана

Сайт: https://anuarbekroza-bit.github.io/kit-site/

## Как менять сайт без кода

1. Откройте https://app.pagescms.org и войдите через GitHub.
2. Выберите репозиторий **kit-site**.
3. Слева выберите, что менять: товары, разделы, тексты, контакты, отзывы, фото.
4. Измените и нажмите **Save**. Через 1–2 минуты изменения появятся на сайте.

Содержимое сайта лежит в папке `_data/`, фото — в `images/`. Паролей и ключей в репозитории нет.
